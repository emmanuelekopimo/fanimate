**Fanimate 0.2.0** adds eleven export formats, makes MP4 with your computer's own video encoder, and gives the app and installer their icon on Windows. It is still an alpha: keep backups, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues).

## Download

| Platform | File |
|---|---|
| Windows 10 and 11 | `Fanimate-0.2.0-windows-x64-setup.exe` (installs for your account, no administrator rights needed) |
| macOS 13 or later, Apple silicon | `Fanimate-0.2.0-macos-arm64.dmg` |
| Linux | `Fanimate-0.2.0-linux-x86_64.AppImage`, `fanimate_0.2.0_amd64.deb`, or `Fanimate-0.2.0-linux-x86_64.flatpak` |
| Portable (no install) | `fanimate-0.2.0-<platform>.zip` or `.tar.gz` |
| Browser | `fanimate-0.2.0-web.zip` (host the folder; see [the web build](https://github.com/toonittmedia/fanimate/blob/main/docs/web.md)) |

If you have 0.1.0, Fanimate offers this update itself. The installers are **not code-signed yet**: on Windows choose *More info › Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. `SHA256SUMS.txt` lists checksums for every file. Full instructions: [Installing and updating](https://github.com/toonittmedia/fanimate/blob/main/docs/install.md).

## New in this release

### More ways to export

**File › Export Video** now lists formats in groups, with a line saying what each is for and what will make it.

With nothing else installed:

- **MP4 (H.264)** with sound, made by Windows' or macOS's own video encoder, using the graphics card where it can.
- **MP4 (AV1)**: royalty-free and small, for browsers and recent players (no sound yet).
- **AVI, uncompressed**: large files any editor opens, with sound.
- **Animated GIF** and **animated PNG** (full colour and transparency).
- **PNG, TIFF and OpenEXR sequences**, one picture per frame. EXR is linear light for compositing.

With [FFmpeg](https://github.com/toonittmedia/fanimate/blob/main/docs/install.md#more-video-formats-with-ffmpeg) installed, also:

- **MP4 (H.265)**, **WebM (VP9)** and **MKV (H.264)**.
- **ProRes 4444** (with transparency), **ProRes 422 HQ** and **DNxHR HQ** for editing in Final Cut, Premiere, Resolve and Avid.
- **Animated WebP**.

**Edit › Preferences › Video formats** says what your computer can make, finds FFmpeg wherever the usual installers put it, or lets you choose it. A format that needs FFmpeg stays in the list marked "needs FFmpeg", and choosing it explains how to get it.

Every format now converts and tags colour the same way (BT.709), so a render looks the same whichever format you pick. MP4s from 0.1.0 could look slightly off in some players because they were untagged.

On the command line, `fanimate-cli formats` lists every format and what makes it, and `fanimate-cli export` takes `--format` and `--ffmpeg`.

### FFmpeg is no longer included

Fanimate no longer ships FFmpeg. MP4 comes from the system's encoder on Windows and macOS. On Linux, install FFmpeg from your distribution for MP4 (H.264); AV1 MP4, AVI, GIF, APNG and picture sequences need nothing. Updating removes the FFmpeg that 0.1.0 installed. See the [video export note](https://github.com/toonittmedia/fanimate/blob/main/docs/legal/video-export.md) for why.

### Fixes

- **Windows:** `fanimate.exe`, `fanimate-cli.exe`, the installer, the Start menu, the taskbar and Settings › Apps now show the Fanimate icon. 0.1.0 showed a blank program icon.

## Known limits

Everything listed for [0.1.0](https://github.com/toonittmedia/fanimate/releases/tag/v0.1.0) still applies. Also:

- AV1 export has no sound yet.
- Windows "N" editions need Microsoft's free Media Feature Pack for MP4.
- The Flatpak can only use an FFmpeg inside your home folder.
