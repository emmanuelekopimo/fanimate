**Fanimate 0.1.0 is the first public alpha**: free, open-source 2D character animation with Moho-style rigging, on Windows, macOS, Linux and in the browser. It is an alpha. Expect rough edges, keep backups of anything important, and please [report what goes wrong](https://github.com/toonittmedia/fanimate/issues). Every report helps us reach 1.0.

## Download

| Platform | File |
|---|---|
| Windows 10 and 11 | `Fanimate-0.1.0-windows-x64-setup.exe` (installs for your account, no administrator rights needed) |
| macOS 13 or later, Apple silicon | `Fanimate-0.1.0-macos-arm64.dmg` |
| Linux | `Fanimate-0.1.0-linux-x86_64.AppImage`, `fanimate_0.1.0_amd64.deb`, or `Fanimate-0.1.0-linux-x86_64.flatpak` |
| Portable (no install) | `fanimate-0.1.0-<platform>.zip` or `.tar.gz` |
| Browser | `fanimate-0.1.0-web.zip` (host the folder; see [the web build](https://github.com/toonittmedia/fanimate/blob/main/docs/web.md)) |

The installers are **not code-signed yet**. On Windows choose *More info › Run anyway*; on macOS right-click Fanimate, choose *Open*, then *Open* again. You only need to do this once. `SHA256SUMS.txt` lists checksums for every file. Full instructions: [Installing and updating](https://github.com/toonittmedia/fanimate/blob/main/docs/install.md).

## New in this release

### Bring your Moho and Animate work

- **File › Open Moho or Animate Project…** (Ctrl+Shift+O) opens Moho `.moho` / `.mohoproj` and Adobe Animate `.fla` / `.xfl` projects as new Fanimate projects.
- **From Moho:** vector layers with their curves, fills and outlines; point animation; groups; bone layers with bones, angle animation, limits and binding; switch layers; image layers; layer transforms and opacity.
- **From Animate:** drawings, rectangle and oval objects, layers and folders, keyframed drawings as frame-by-frame layers, symbols moving with classic tweens, nested graphic symbols, and library pictures.
- After every import the status bar lists what did not come through exactly, such as Smart Bones, masks, gradients or text, so you know what to check. See [what imports](https://github.com/toonittmedia/fanimate/blob/main/docs/import.md).

### Installers that keep themselves up to date

- Installers for every platform: a Windows installer, a macOS disk image, and an AppImage, `.deb` and Flatpak for Linux.
- **Updates:** Fanimate tells you when a new version is out, with a button in the status bar. It downloads only when you ask, checks the download's signature before running anything, asks you to save, and restarts into the new version. Turn the check off in Preferences to stay on one version during a production.

### Crash reports you control

- If Fanimate closes unexpectedly, the next start recovers your work and then offers to report the crash. Reporting opens a GitHub issue with the details filled in, for you to read and send. Fanimate never sends anything on its own.

### Fanimate in the browser

- Open a project (zipped `.fnm`), a Moho file or an Animate `.fla` in a WebGPU browser to watch it, scrub it and toggle layers, with nothing to install. Handy for showing work to a director or a client.

### Smaller things

- **Window › Workspace:** panel layouts for animating, drawing, rigging, frame-by-frame work and review.
- **Command palette** (F1 or Ctrl+Shift+P): smarter search ("nvl" finds New Vector Layer); commands you can run now come first and recent ones are remembered.
- **File › Import** now lists SVG files in its file dialog.
- New command-line tools: `fanimate-cli import` converts a Moho or Animate project, and `fanimate-cli corpus` checks a folder of them.

## Everything else in Fanimate

If you are new: Fanimate draws with a pressure-sensitive vector brush, pen and shape tools. It animates by keyframes, point by point or frame by frame, with onion skin, a light table and an X-sheet. It rigs with bones, inverse kinematics, smooth binding, Smart Bones and actions, and bends pictures from Photoshop files with bones. It lip-syncs dialogue to mouth switch layers, and exports MP4, MKV, GIF and PNG sequences through a render queue that keeps working after you close the editor. Your work is kept after every change, so a crash loses nothing. The screen follows Moho Pro's layout, with standard shortcuts or Moho's own.

## Known limitations

- **Imports:** Moho actions and Smart Bones, bones that move or stretch, and masks are left out. From Animate, shape tweens and newer motion tweens are held at their keyframes, and text, gradients and filters are simplified. The importers were built against a small set of openly licensed files; **send us Moho and Animate files you can share** ([how](https://github.com/toonittmedia/fanimate/blob/main/corpus/README.md)) so they improve.
- **Self-update** was tested end to end on Windows. The macOS and AppImage paths have unit tests, but this is their first release.
- **The web build** only plays and checks projects; it needs WebGPU and plays no sound.
- **Not signed:** see Download above.
- Not yet measured on the reference hardware for macOS and Linux.

## For developers

- New crates: `fanimate-import` (Moho and Animate importers, a lenient ZIP reader) and `fanimate-web` (the browser player).
- `fanimate_fnm::load_from` reads a project from any file source, such as a ZIP archive in the browser.
- The release workflow builds the installers and the web build, signs the update files, and attaches SHA-256 checksums.
- The `.fnm` file format is unchanged (version 3).
