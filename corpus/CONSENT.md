# Corpus consent record

One row per file in the import test corpus, added in the same change as the file. See [README.md](README.md) for the rules.

| File | Made by | Permission from | Licence or terms | Location | Date | Issue |
|---|---|---|---|---|---|---|

Column meanings:

- **File:** path under `corpus/`, or a short name for a private file.
- **Made by:** the author, as they wish to be credited.
- **Permission from:** the person or organisation that agreed to the use (often the author).
- **Licence or terms:** an SPDX identifier such as `CC0-1.0` or `CC-BY-4.0`, or `test-only` for files we may test with but not share.
- **Location:** `repo` if the file is committed here, `private` if a maintainer holds it.
- **Date:** when permission was given (YYYY-MM-DD).
- **Issue:** the issue where the file was offered.
